# Marble Run Lab design

The user's pinned direction overrides the concept seed: a premium miniature toy workshop on an ivory tabletop. Operate mode: scene first, compact controls around its perimeter. Code-first functional 3D geometry is the visual artifact; no raster mockup or illustrative stand-in.

DM Sans for controls, Space Grotesk for the brand and workshop title. Ink #303b36, moss #426653, ivory #f7f6f2, quiet borders #e4e5df. Coral #e78c70, cobalt #567ad4, butter #e9c864 and mint #8ebdad plastic. Brushed metal support columns, warm floor with a restrained technical grid. The permanent library is left, contextual controls right, transportation in a floating lower bar. Mobile uses an optional bottom drawer.

Signature: a composed perspective view of a real 3D marble machine with small START/FINISH callouts and an opening dolly. Placement previews and connector halos convey mechanics. Reflections belong to the toy, not the UI. Large quiet workbench, consistent stroke icons, tactile active buttons. Responsive panels, 44px touch actions, accessible keyboard equivalents, reduced motion.
